## How to Run

1. **Clone the repository:**
   \\ash
   git clone https://github.com/Bhoomika-132006/hackerrank-java-solutions.git
   cd hackerrank-java-solutions
   \
2. **Navigate to any challenge folder:**
   \\ash
   cd Java/Introduction/Welcome-to-Java
   \
3. **Compile and execute:**
   \\ash
   javac Solution.java
   java Solution
   \
---

## Coding Standards

- **Naming Convention:** All solution source files are named \Solution.java\ matching the primary class.
- **Organization:** Subdomains correspond to HackerRank Java tracks (e.g., \Introduction\, \Data-Structures\).
- **Documentation:** Each challenge directory includes a \README.md\ and submission verification image.
